01｜先看证据强度，再看能省多少钱

A｜公开规则已核实

当期官方政策／学校费表支持该机制。仍须取得孩子本人录取、适用报价或资助信；A不等于已获批准。

B｜条件候选／缺口未闭合

真实官方线索存在，但当届名额、国际资格、续期或版本有缺口。下一步是定向核实，不是先交不可退费用。

C｜家庭规划假设

如晚两年出国、亲属照护或雇主福利；需要按家庭算账，没有全国保证额度。不得包装成政策优惠。

  1. 确认本人资格年龄、国籍、年级、家长身份、地区。
  2. 拿到计价证据当年国际费表＋逐项个案报价。
  3. 锁定减免条件正式授予、期限、续期、叠加与撤回。
  4. 算两年及退出无奖、无工作、涨费、回国四种压力情景。

阅读方法：下列每条路径都回答“谁能试 → 证据在哪里 → 怎样办理 → 钱怎样算 → 何时停止”。示例汇率沿用总览的固定情景，不是当日兑换价；未确认的优惠一律不进入家庭保底预算。

02｜路径01：先改学费基数，通常比追奖更稳

优先调查已有证据执行动作停止条件
澳洲低普通国际费公校NT 2026费用按学段明确；不是依赖奖学金才低。[AU01]按实际入学年重新索价→确认学校／年级名额→取得CoE及未成年照护安排→比较完整家庭成本。2027报价未出、无合适学校或照护，不能把2026数字锁定到未来。
新西兰公立／state-integrated已列Pompallier与St Peter’s Gore国际费表；融合学校不等同昂贵独立私校。[NZ10][NZ12]核真实校名和校区→国际入学要求与Code→信仰生活适配→将attendance dues等所有必缴项计入。复制同名另一校报价，或把本地受补助学生的低费用当国际学费。
美国宗教校IGDVS基础价低；语言、寄宿和学校生活要求独立审查。[US05][US06]先做英语与年级评估→确认I-20／校区→拿到含英语支持的完整报价→核素食、宗教活动等真实适应。家长或孩子不接受学校生活方式；英语加费和照护后超过家庭承受力。

03｜路径02／03／06：NSW三种优惠不能混成一个“永久低价”

A｜公开条款明确；个案资格待批 适用于相关国际项目，不可套到所有临时居民。2026年标准寄宿优惠与10%地区／兄弟姐妹规则分别阅读。[C01]

机制操作／材料保守算账边界
地区10%学校须在政策范围；先确认寄宿可提供和实际校址。2026 Years7–10：18,000×90%＝AUD16,200≈¥77,760。+10%汇率＝¥85,536，已超纯学费线；2027需用新费表。
兄弟姐妹10%提供同一父母关系及同时在读证明；核第几个孩子享受。只算符合条件孩子；已有两个孩子不是总账都减10%。地区与兄弟姐妹两项不可互叠；兄姐离校后需重新确认。
标准寄宿一次性优惠2026年1月1日至12月31日标准homestay新生：ISP为AUD3,500；Study Abroad为1,750；parent-nominated homestay排除。仅ISP且获3,500时：18,000−3,500＝AUD14,500≈¥69,600。不自动延续2027、不先叠加10%；寄宿本身另收费。先拿项目类别及个案优惠确认。

一张低学费单，不等于一个低总价方案

演算：2026寄宿AUD520／周，假设仅计40周已是AUD20,800≈¥99,840；与优惠后学费合计约¥169,440，仍未计全年剩余时间、保险、交通等。40周只是演算，不是全年住宿保证。若原本有合规低成本照护，为拿优惠改买寄宿，可能反而更贵。

  1. 提交前确认地区／兄弟姐妹资格与拟入学批次。
  2. 出报价时要求发票分别列原费、具体优惠及有效期。
  3. 付押金前书面确认能否叠加；确认住宿及退款条款。
  4. 下一年去掉一次性优惠，以新费表重新过8万与现金流测试。

04｜路径04：奖学金要拆成“能申请”和“已获奖”

Burnside High School：有明确国际生奖项，但不是自动折扣

A｜奖项规则；B｜个案获奖及当届报价 每年6名，首年公布学费的20%；覆盖学业、创意／技术或体育方向。父母已有或打算申请新西兰工作签证者被排除，不能与“父母工签带来的本地价”想当然叠加。[C02]

  1. T−12～9个月选择批次；按官网当届截止申请，不能套去年的时间。
  2. 准备证明近年成绩、特长证据、教师／教练推荐、英语陈述及短视频。
  3. 同时申请学校录取、语言、照护和奖项是不同审查，不要只交奖项表。
  4. 收到书面结果确认金额、适用费用、只首年、学生义务与支付时点。
当前可做财务演算未获奖／次年
按网页每年年中批次2月28日截止规则推算，2027年中批次应提前于2027-02-28申请；这是日期推算，须确认当届仍开放。若当届原学费为F：首年确认获奖后为0.8F；F须另取当届报价，不能把2026价当2027价。续年按完整新年费F₂，除非获得新的书面资助；6个名额不构成可预测中签率。

研究价值：不只记录“有20%”，还要记录排除资格、批次、首年、名额与未获奖备选。孩子希望赴NZ而父母也计划工签时，应先选家庭身份路线，再比较两套互不混用的价格。

05｜路径05／08：高额资助与政府、宗教补贴的四道门

证据案例可以研究的路必须补齐的材料／反例
Andover需求型资助[US10][US11]国际申请者可进入资助审查；被录取且有学校认定的经济需要，才可能显著降成本。入学申请与资助同时安排；收入、资产、税务及非标准收入说明。高额资助≠低门槛录取；不隐瞒中国房产。
爱尔兰SEC宗教助学金[IE09]符合宗教、居民／收入及指定学校等条件的家庭才继续。原大陆直接留学家庭不能只因学校有教会背景就套用。需先核2026/27适用收入年度、身份及学校。
英国学校bursary／特定音乐项目[UK05][UK06][UK07]逐一筛住所、训练水平、家庭收入和学段。“学校有bursary”不证明接受常居中国的家庭；国家艺术项目不是所有国际中学生通用补助。
澳洲Pal奖项排除例[AU13]公开奖项不等于该校所有签证持有人可获奖。已核2026奖项限公民／PR；普通大陆国际生不计入可用减免。
  1. 国籍／居留项目有没有明确接受本人身份？
  2. 项目／学段是否真是K–12，而非大学或周末课程？
  3. 需要／能力是否符合收入审查或专业水平？
  4. 当届授予名额、截止、金额与最终通知是否齐全？

四关中任何一关不满足，就保留为排除证据；不是继续用“可以试试看”把它计进预算。大学国际奖学金、国内学生交通补助等也不能直接移植到国际中小学。

06｜路径07：父母身份改变收费，比孩子兼职影响更大

路线为什么可能省先做什么不要漏算
澳洲合资格工作签证家属不同州的公校临时居民费或豁免与孩子本人500国际费不同。[AU27][AU28][AU31]匹配父母真实职业与获批签证→选州／住址→核子女收费身份→申请学位。不是全国统一免费；不靠虚假雇佣、假地址或失效工签续用减费。
新西兰合资格工签／特定研究路线依附属子女规则可能取得domestic student待遇。[NZ04][NZ05][NZ06]先审父母签证和担保子女条件，再核学校费；不要倒过来为“省学费”报昂贵课程。家长学费、工签条件、收入门槛、求职空窗与全家住房。
英国／爱尔兰／美国随父母居留孩子的学校资格可能与独立国际生路径不同。[UK15][IE10][US01]父母工作路线与家庭团聚先成立→合法住所→学位和费用核验。子女就读公校不等于全家获得移民；各类随行签证的孩子也不必然能打工。
家庭净收益＝孩子减少的费用＋新增税后收入−搬迁和住房增量−父母学习／签证成本−放弃的收入。

先用“没有找到工作”的情景做保底预算。更多现行签证边界在家长工作／身份页；本次不把这条路线改写成移民保证。

07｜路径09：交换可以省一个阶段，但不能偷偷换算成年年免费

可调查路径应取得的证据不可承诺
澳洲／新西兰认可中学交换[AU23][NZ01]政府认可组织、当届中国申请资格、对应学校和期限；组织费用、住宿、机票、保险及返校学分。付费Study Abroad项目不自动免学费；找到海外伙伴学校也不等于本人已获交换名额。
美国J-1中学交换[US03][US12]指定sponsor、年龄与既往经历资格、寄宿安排、完整项目收费、学期或学年及回程计划。不是多年自由选校毕业路径；工作限制与F-1不同，详见学生打工页。
UWC两年IB与需要型资助[X01][X02]中国当届渠道、年龄、申请类别、收入资产、资助覆盖项目与分校分配。不是小学／初中交换；国家、校园、奖额不保证。中国渠道Regular与Early资助条件不可混。

用于预算的数字应是“整段项目净总价”，而非海外学校名义学费0。申请前请国内学校书面确认学籍、复学年级与成绩接续；这一步决定它能否成为低风险英语体验，而不是多花一年。

08｜路径10：英国16+ Further Education，值得补查的另一条高中路径

B｜真实官方线索，但不发布为“保证6万元读英国高中”

16岁以上可另研究有相应担保资格的学院A-level课程，而不只筛Child Student独立私校。签证应按Student路线与实际CAS判断；这不等于普通state school向留学生免费开放。Student与Child Student工作权对比 →

Chichester官方页面支持什么仍缺什么怎样核实
国际A-level：16+、两年课程；页面年费£8,500，有限£2,250奖学金按面试和学业结果评选。[C04]当届大陆资格、具体名额、奖额是一次性还是逐年、可选科目、当前CAS资格。给国际招生办完整画像，要求当届offer、逐年费用和奖助条款；核最新Student sponsor登记。
课程页英语写UKVI SELT各项B2；价格PDF列IELTS5.5。PDF第4页费用也为£8,500。[C05]英语说明不一致；PDF封面“Published October2026”晚于2026-09-16核查日。保留矛盾记录，不自行认定某个较低门槛有效；要求学校确认版本、考试类型和单项要求。

无奖学金情景

£8,500×9.7＝¥82,450，略超8万元纯学费线；+10%汇率为¥90,695。

仅当£2,250减当年学费获确认

(£8,500−£2,250)×9.7＝¥60,625；+10%汇率为¥66,687.50。次年是否同减，必须另有文字。

家庭账单仍未闭合

教材／设备、16–17岁住宿与假期照护、监护、签证、IHS、交通均另核；不能复制18+宿舍低价。兼职收入按0作基础预算。

  1. 准备成绩与英语确认中国年级／成绩如何等同入学要求及选科先修课。
  2. 申请课程＋奖项面试与资助并行；无奖时是否可负担要先决定。
  3. 核CAS和照护Student担保、真实课程层级、未成年同意及安全住宿。
  4. 付费前锁条款当届价格、税费、退款、每年奖助与无工作收入预算。

这是对上一版“英国主要看私校”的补充，而非把普通英国公校改判为可直接免费申请。课程／学段适配比校名是否带college更重要。

09｜路径11：英语准备与学校已含服务，能减少隐性账单

IGDVS 2026/27按语言级别分别收ELD费；例如ELD1每学期USD4,950，ELD3为2,500，两学期差USD4,900≈¥35,280。这是两种分级情景的差额，不是参加国内补习就保证获得的折扣。最终分级、是否必修及何时退出由学校决定。[C03]

  1. 申请前拿分级规则问清测试、英语课是否额外、复测与退出机制。
  2. 国内准备做投入产出实际语言提升与适应价值优先；把培训费和时间算进去。
  3. 对比学校完整套餐英语支持、教材、接机或活动已包含的项目，不重复购买。
  4. 拿最终账单确认不只比较基础学费；若语言级别未定，就预留较高费用情景。

其他节省线索如学校借用教材、校服二手店、设备借用计划，应向该校核实国际生能否用、押金及损坏责任。它们属于附加费优化，不是另一个已确认奖学金；不要凭地方居民福利推出国际生同样享有。

10｜路径12／15：住宿和雇主福利能省，但不能省掉监护

家庭情况可尝试的动作先拿的证据预算口径
当地有可靠亲属请求学校认可的亲属／指定照护安排，比较走读与寄宿。真实关系、住所、背景／安全审核、学校与签证许可；谁负责周末、假期及紧急医疗。房租0也要计餐饮、交通、监管或检查费；家庭照护劳动不是免费无限供给。
家长可合法同住比较亲子租房与学校寄宿，但独立核家长工作权。合法居留、住房、收入证明与照护排班；不可通过“旅游轮换”假装长期居住。孩子省下寄宿费不等于抵销家长整年住房和放弃的工资。
家长有真实跨国雇主向HR询教育津贴、搬迁、机票或医疗福利。签署劳动合同／福利手册：国际学校是否覆盖、孩子人数、上限、税务、报销时间和离职追回。未获雇主确认＝0；报销后净承担额下降，但学校原学费不变。此项是个案核验方法，不是统一政府计划。

低龄照护底线请结合陪读与住宿原专题。英国Child Student住宿规则与家长陪同年龄限制已有专门原始依据[UK13][UK12]；其他国家不能照搬英国年龄线。

11｜路径13／16：减少海外年份、控制附加费与退出损失

调整时间，比幻想打满工时更可控

比较“国内继续读＋国内英语准备＋高中再出国”与“小学起全程海外”。省的是减少的海外学年成本，减去国内替代教育、衔接及新增申请费用；不得直接说每年学费变低。

短期体验不等于毕业学历

一学期体验可能用于测试适应，但要核国内学校复学、海外课程学分和签证。已处于IB／A-level等连续课程的学生，仓促转学可能增加一年成本。

付款计划改善现金流，不创造奖学金

逐期缴费可能有手续费；用全年总支付比较。可退押金是暂时占用资金，不能算永久学费，也不能当可自由花掉的现金。

先查退出条款再交钱

签证拒签、入学前退出、开学后退出、家长身份变更、退宿分别记录通知期与扣费。付款前核学校账户；奖助“代理费”或保证获奖不能当资格证明。

IGDVS公开分期方式另收每次处理费，恰好说明“分期＝省钱”不成立。其家长志愿服务替代部分捐款的机制，也不能证明持无工作权签证的家长可以合法参加换费劳动；必须另核身份，不纳入默认方案。[C03]
