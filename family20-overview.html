01｜先说结论：可研究的组合存在，但还没有“人人可办”的产品

1＋1一名成人＋一名孩子
¥20万逐年净支出上限，不仅看平均
4–5年教育连续性＋身份续期
¥6万纯学费目标；可以更低

加拿大：教育语言匹配，但就业入口最难

英语公校＋符合条件的工签家长，值得先查真实雇主。不能把“能做服务员”当成“境外服务员工签容易获批”。看工签、公校与续期 →

葡萄牙：先看真工作与未成年团聚

适合接受葡语公校的家庭继续筛查；英语私校要另拿学年与年级报价。移民新法和办理时间不能沿用旧攻略。看新法、工资与学校 →

西班牙／希腊：便宜生活不能解决等孩子的问题

普通雇员家庭团聚通常有前置居留要求。家长先行与亲子同步是两种不同产品，不应混着计算。西班牙 → · 希腊 →

芬兰／丹麦：低学历不等于没有机会

芬兰真实雇员路线、丹麦真实厨师技能路线可继续核验；不过家庭收入、岗位能力和学校语言都要过关。北欧南欧8地筛查 →

尚未形成可成交的雇主＋学校组合。本轮确认的是公开政策与费用证据、条件性路线和预算敏感性；没有为此家庭取得工作合同、签证、团聚批准、学校学位或住房报价。数字达标，不代表路线已可执行。

02｜把用户画像变成可筛选字段

字段本轮基准为什么重要
家庭身份假设中国大陆护照、当前在大陆、无既有欧盟／加拿大居留；1成人＋1孩子另一位家长同意、监护权、亲子关系与子女出境材料必须核验；不是自动视为单亲。
孩子未指定时按10–12岁入境；分别看当地语言公校和英语授课6–9岁照护成本更高；13–16岁跨学制、考试科目与高中学费风险更大。年龄是情景，不是已知事实。
家长学历中学／职业教育或较低学历；不使用硕士、博士、研究学生路线但低学历可以有真正的厨师、汽修、焊接等工作能力。
语言与经验英语弱；当地语言未建立；职业证据尚不明确必须分“有技能但语言弱”和“无技能无语言”。二者不能用同一承诺。
资金20万元是每年净现金支出线，5年100万元上限首年安置费、签证资金要求与押金占款可能高于长期平均；不能只拿总额除5。
排除项不靠买岗位、挂名上班、旅游黑工、虚假材料或孩子工资劳动收入仅在合法获准、岗位真实且照护安排可执行后进入情景。

03｜正确顺序：工作与孩子居留先于学校购物

  1. 1. 接受哪种教学语言？必须英语授课 → 先看英语公校资格／英语私校完整账单；可当地语言 → 西葡希公校进入候选。
  2. 2. 家长能合法取得什么许可？拿真实经验对照岗位与许可条件；“当地缺人”不是批准文件。无对应入口就停止报价。
  3. 3. 孩子什么时候能来？同申、家长获批后申请、住满1–2年后团聚分开。不能让孩子长期旅游补团聚等待。
  4. 4. 工作、学校、住房能放在一张地图上吗？算通勤、放学接送、周末班与暑假；不拿边远租金配大城市工资和远处英语学校。
  5. 5. 年度与五年两条预算线都过吗？先看0工资，再看保守工资；税、保险、托管、服务费、涨价和汇率不能遗漏。
  6. 6. 第二次续期或失业时还能继续吗？孩子身份及免学费资格可能跟随家长变化；每年保留回国衔接与退出资金。

04｜三种教育产品要诚实区分

产品教育结果不能混用的宣传
英语授课学校主要学科使用英语，仍需核课程、学位、英语支持与孩子适应学校网页有英文／当地游客多，不等于学校英语授课。
当地公校＋英语补充接受西语／葡语／希腊语等主教学语言，额外英语课程与国际活动这可以是多语成长方案，但不是英语沉浸式国际学校的廉价等价物。
家长先工作、孩子后团聚先建立居留、收入和住所，再开启孩子海外教育阶段家长先行1–2年不能记为孩子已经留学1–2年，也不能删掉两地家庭成本。

05｜一个大人能上班，也必须能接孩子

工作型态对照护的影响预算处理
学校时段固定班最有希望，但通勤缩短可工作窗口先用实际校历与排班核小时；工签可能要求固定工资，不能无限减班。
餐厅晚班／分段班放学后、晚饭、周末正是工作高峰需要真实成年照护人；不能默认让小学孩子独自在家。
酒店／清洁早班可能早于上学时间，地点分散早餐托管、接送或雇主调整排班，全部书面落实。
住家照护／农场包住雇主房间可能不能住孩子，地点可能无匹配学校“包吃住”仅覆盖员工，不等于两人房租归零。
暑假／病假／学校临时停课全年收入不是学期内每周工作小时乘52假期营、临时看护、停工少赚分别算；有小孩工资一律按0。

这里不设统一“16岁就能独立生活”判断。当地儿童保护规范、孩子成熟度、夜间照护与学校要求须个案确认。收入、托管与开支怎么放进同一张表 →

06｜4–5年路线：申请时钟、孩子教育时钟与预算时钟

T−12～6个月｜国内准备，不先买长期学校套餐

记录家长真实职业年限、工资／社保／推荐证明；孩子成绩与语言；选择教学语言。语言与技能培训先设上限，避免培训贷款。

T−6～0个月｜三项批准相互校验

真实雇主与许可、子女随行／团聚资格、学校收费类别；取得房租和托管报价。没有子女同步依据就按分离方案评估，不能假装已闭合。

第1年｜最危险的是现金流与照护

预算列0收入基线和6个月收入敏感性。到岗不等于立即领全年工资；税号、医疗、租约、入学、接送与试用期逐一落实。

第2年｜续签、实际收入与家庭团聚

核实合同续期、工资是否满足许可及带娃门槛；有等待期的国家，孩子可能到此时或更晚才能开始海外教育。

第3～4年｜升学段与停留目的复核

小学升初中／初中升高中可能涨费或更换教学语言；临时英语项目到期不能假设自动续读。没有明确续签前，不预付多年不可退学费。

第5年｜继续、回国或另走长期身份

五年预算结束不等于取得永居或入籍。按当时法定资格、语言、收入、居住连续性重新评估；回国衔接提前一学年准备。

07｜中介真正能交付什么：把信息差变成透明证据

可收费的价值

家庭筛查、证据核验、学校与住房协调、翻译和家校支持、年度复查；如涉及持牌法律／移民／招聘服务，须由有资质主体按适用规则提供。

不可承诺的结果

保证获聘、保证签证、包免学费、五年包永居；不能因为家长不懂外语而隐藏团聚限制、劳动条件或退款条款。

签约前交付给家长

一页中文风险说明＋原始来源；逐项费用与第三方佣金；谁收钱、谁承担失败损失、哪些款可退；让家长能独立复核。

商业筛选应问“谁最需要且能够负担这项服务”，不是“谁最不容易发现问题”。特别是工签绑定雇主的低语言家庭，要把独立求助、保管护照和退出能力设计进服务。公平招聘与收费边界 →

08｜本轮最值得推进的三类个案

优先级家庭条件下一项必须拿到的证据
1｜加拿大英语公校组合家长有可被验证的岗位能力；雇主愿意合规申请；孩子符合学区免国际费类别真实工作与LMIA／豁免依据、学区书面收费认定。
2｜葡萄牙工作＋公校组合接受葡语教学与英语补充；真实雇佣且孩子手续有明确依据雇主合同、领馆和AIMA对未成年子女路径确认、当地学校与房租。
3｜芬兰／丹麦技能候选有实际技能、愿学工作语言，能满足更高家庭净收入岗位代码与工资、孩子身份、教学语言与实际学位。
暂不成交无技能、无语言、无雇主、只靠“落地能打工”维持预算先国内准备与免费筛查；未通过前不收大额不可退套餐款。
