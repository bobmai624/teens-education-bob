01｜不要把四个问题当成一个“留学移民套餐”

  1. 孩子是否能入学学校年级、英语、国际招生和课程要求。
  2. 家长是否能同住家长自己的居留依据、年龄期限和照护责任。
  3. 家长是否能挣钱自己的工作权、真实岗位与税后收入；孩子录取不会自动产生工作权。
  4. 将来是否能留下永久居留／入籍另有资格与年限；短期许可与未来政策都不能保证。

正确的顺序是：先检验合法可行性，再比较家庭现金流。若必须靠尚未允许的工作才能付下学期费用，这条路线尚未达到可执行标准。

国家以孩子留学为主的家长安排父母自身路线另评估
澳大利亚590监护签证不得工作。[AU24]真实482／父母研究或其他学生课程；子女公校收费逐州、签证及课程核。看州级减免矩阵 →
新西兰Guardian Visitor默认无工作权；可申请条件变更，获准后限定周一至周五9:30–14:30工作。不是自动自由工签。[NZ03]合资格工作签证、博士或合资格学生的伴侣工签链；收入、职业、子女许可各有门槛。看身份链与限制 →
美国孩子F-1不能给父母F-2；B类访问无工作权。[US02][US04]真实工作、研究或父母本人F-1与子女F-2；父母自己的学费／工作限制不能遗漏。看公校与工作边界 →

03｜“父母读书，孩子免费”必须经过五层核验

  1. 父母真的需要这个课程吗？学历、语言、职业目的与录取均真实；不是买一个名义学籍。
  2. 这类课程可带家属吗？授课硕士、研究硕士、博士、VET和语言课不可互相套用。
  3. 谁取得哪种工作权？主学生、伴侣与监护人是不同人；不能把配偶工签规则套给陪读签。
  4. 孩子拿什么实际身份？直接附属、先伴侣工签再附属等机制可能不同；必须完成每一步审批。
  5. 当地如何认定学校收费？核孩子与父母签证、学校／住所、课程性质、奖学金覆盖、年龄及期限。

新西兰官方列有合资格学生支持伴侣工作、再由伴侣支持受抚养孩子学生签证的安排；并不等于任何学生家长可直接让孩子免费入学。[NZ05] 英国研究与授课型课程的家属规则也不相同。[UK16]

04｜一个家庭要有三个账本，收入按税后、可实现口径

账本必须包含不能做的抵扣
A 学费筛选每个孩子全年基础学费＋必需英语课−已确认学费减免不把尚未获得的奖、未来兼职、第二个孩子折扣算给第一名
B 学校及照护行政／建校／设备／考试／保险；住宿、监护、接送；长假闭校安排不重复加套餐已含学费；可退订金单列现金占用，不全当永久支出
C 全家现金流父母学费、租房、生活、交通、保险、签证、税费、国内仍保留的家庭支出与应急资金不能以工作权等于找到工作，或以税前工资等于可用于缴费的钱
可持续结余＝合法且可靠的税后收入＋可动用非借贷教育资金−全家年度现金支出

同时记录父母离职造成的国内收入损失，它是机会成本，不要再作为实际海外现金支出扣第二次。

纯演算示例，非任何城市报价方案A：陪读，无工作收入方案B：父母有真实合资格工作
孩子年度学费60,000元0元（仅假定已书面确认免课费）
其他学校、住房、生活、照护等180,000元220,000元
全年实际现金支出240,000元220,000元
已确定合法税后工作收入0元260,000元（纯假设）
需储蓄补足／当年结余须补足240,000元结余40,000元
压力情景：全年收入只实现一半仍需240,000元需补足90,000元；若身份随失业变化，孩子价格与居留还要重评

此例只说明计算方法，不是家长收入预测、免学费资格认定或移民推荐。先有合法身份与可核合同，再使用个案数据；学费便宜也可能是全家成本更高的路线。

05｜按可承受风险分家庭，而不是按“阶级”贴标签

家庭资金／职业情况更合适的第一步不应承担的风险
储蓄有限，必须靠家长收入维持优先评估真实工作可行性；若不成立，保留国内读书和阶段性英语体验低龄长线陪读＋家长不得工作＋假定未来转工签；没有第二年现金来源
有稳定收入及数年教育储备比较公立普通价与孩子适应、城市照护、家长职业连续性为小额学费折扣牺牲稳定收入；把首年优惠当永久价格
预算宽裕但强调性价比教育适配、住宿质量、可退出性优先；仍核资助是否真符合需要以高消费或名校录取推断未来移民成功；忽略孩子意愿
父母已有学术／国际职业基础先利用真实职业或研究条件评估全家路径购买虚假岗位／邀请函、名义就读或隐瞒资金与家庭关系

06｜移民是后续独立目标，不是中小学学费的附赠品

阶段可以提前做不能承诺
小学／初中英语、学习适应、家庭居住记录；保留国内衔接信息某国读书几年自动PR；孩子入学自动让父母合法工作
高中选课与毕业资格、大学预算、成人年龄临界点、本人签证后续高中课程直接等于毕业工签或职业移民资格
大学／工作在当时规则下重新核课程、职业、语言、就业与居留条件十年后的政策、职业清单、收入门槛或雇主担保结果
父母长期身份独立职业／家庭／研究路线审核；比对个人年龄、学历、语言、岗位和资金靠未成年孩子未来移民来解决父母今天的收入与永久居留

各国规则在国家页分别链接。英国Long residence与爱尔兰Stamp4、长期居留及自然化的计时并不相同，不能跨国套用“住满若干年”。[UK11][IE15]

07｜如果失业、停学或预算断裂：预案必须与申请同步

  1. 出发前｜做退出预算建议预留6–12个月基本支出与返程／过渡资金，具体额度按家庭；这是风险管理建议，不是签证最低资金要求。
  2. 变化发生｜立即核状态找学校和合资格移民专业人士确认个人许可、宽限／新申请要求及收费变化；不要猜“有学籍就能继续合法居留”。
  3. 维持安全照护核家长离境、住处变化或奖助终止后孩子是否仍有全年照护；不要只保课程忽略住宿。
  4. 决定续读／回国比较剩余现金、下一学年无奖学费和国内接收结果；按退款条款办正式退学，不靠失联。
  5. 带走完整材料成绩单、课程大纲、出勤／在读离校证明、签证与居留记录；国内学籍与考试资格按省市学校重新确认。
