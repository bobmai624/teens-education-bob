## Scope and limitations / 研究边界

- 全球报告覆盖 37 个国家与地区案例，不代表所有国家均有已确认可申请或符合预算的路径。
- 陪读与住宿补充报告中，19 个目的地的相关官方机制已核查；其余线索及待核项目在报告内分别标注。这不等于已核实具体家庭的签证资格、学校床位或实地照护质量。
- 人民币 80,000 元是年度学费筛选线，不是全家全年总成本承诺。
- 政策、学费、汇率、入学条件及住宿空位可能变化。申请或付款前应向主管机关及学校再次书面确认。
- 本站是研究资料，不构成个案法律、移民、财务建议或录取保证。来源链接及证据限制见各报告。
- PDF 保留对应报告的研究版排版；网页附加统一导航。澳洲独立专题保留其原研究日期，更新内容应与全球报告及最新补充报告交叉阅读。
